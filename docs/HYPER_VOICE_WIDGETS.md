# Widgets

```jsx
import { VoiceWidgetDashboard } from 'jsvoice/react/kit/widgets';
```

Built-in types include metric, text, list, table, status, transcript, command, assistant, debug, plugin, rule, workflow, notification, etc.

```js
VoiceKitActions.createWidget('metric', 'Revenue');
```

Voice pack phrases: create widget, create metric widget, undo.
