# Storybook

Flagship Hyper Kit components:

```bash
npm install
npm run storybook
```

Open http://localhost:6006

Stories live in `stories/`:

- `VoiceOrb.stories.js` — orb states, status pill, control bar  
- `VoiceDock.stories.js` — dock + command palette  

Static build:

```bash
npm run build-storybook
```

Output: `storybook-static/`
